# SEO Content Strategy

## Workflow

1. Clarify market, geography, audience, product, and conversion goal.
2. Research the live SERP and competitors when available. Use Firecrawl/browser tools for specific URLs and Perplexity/search for broader discovery.
3. Extract recurring headings, content gaps, search intent, objections, and proof points.
4. Produce a brief with target intent, primary/secondary topics, suggested title/H1, outline, FAQs, internal links, and conversion CTA.
5. Flag claims that need primary-source support before publication.

## Quality Bar

- Prioritize useful content over keyword stuffing.
- Treat keyword volume and difficulty as optional if no reliable source is available.
- Keep recommendations implementable for the user's stack.
- For EVERSO, favor water-sports-native topics, safety, conservation, trip planning, gear, and community value.

## Outputs

Default output: concise SEO brief plus outline. Include competitor table only when it adds signal.
