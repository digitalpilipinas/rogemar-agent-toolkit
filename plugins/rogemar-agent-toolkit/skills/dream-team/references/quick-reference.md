# Dream Team Quick Reference

## Common controls

- `@persona`: request a communication lens.
- `squad-a`: request technical perspectives.
- `squad-b`: request a plain-language explanation.
- `all-hands`: request a phased, reconciled review.

## Lifecycle modes

| Mode | Main question | Typical capability route |
|---|---|---|
| Discover | What problem and outcome matter? | research, knowledge base, strategy |
| Design | What should users and systems experience? | UX, design system, accessibility |
| Build | How should this be implemented safely? | plan, first-time-right, domain skill |
| Verify | What evidence proves it works? | review, test architecture, QA |
| Release | Can it be rolled out and recovered safely? | deploy checklist, target release skill |
| Explain | How can this be understood clearly? | plain-language persona |

Use the repository and current task to determine the actual technology and
validation commands. Never infer them from this quick reference.
