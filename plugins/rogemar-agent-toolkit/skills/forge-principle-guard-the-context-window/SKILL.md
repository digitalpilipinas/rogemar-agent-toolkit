# Guard the Context Window

## Forge execution contract

Read [the shared Forge runtime](../workflow-orchestrator/references/forge-runtime.md) before dispatch or a runtime action. This skill supplies the method. The active Forge entry selects the profile router.



Use the orchestrator's [context-efficiency contract](../workflow-orchestrator/references/context-efficiency.md).
Read enough source and failure evidence to make the next decision correctly.
Bulk alone does not justify delegation; a worker must earn its context and
coordination cost. Keep small common rules inline and substantial conditional
detail in references. Native compaction may free space while losing detail;
preserve durable task state and verify critical evidence after uncertain recovery.
