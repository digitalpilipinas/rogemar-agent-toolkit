## Project learning

- For non-trivial work, consult `docs/project-learning/lessons.md` only when an accepted entry is relevant to the current task.
- Treat accepted lessons as advisory. Current instructions, repository contracts, tests, and verified current evidence take precedence.
- Automatic learning is project-local, signal-gated, and candidate-only. The Stop hook passively queues bounded turn metadata and never interrupts normal task chats; a dedicated project-learning task reviews queued turns and candidates require user approval before entering the accepted ledger.
- Never persist raw transcripts, hidden reasoning, tool output, secrets, credentials, personal data, or quoted conversation text.
- Skip persistence in Plan Mode and whenever the user requests no writes or no learning for the task.
- Project learning cannot delegate, edit product code, alter delivery status, modify existing skills, or write Codex memory.
- Never adapt or promote lessons globally or into another project without explicit user approval.
