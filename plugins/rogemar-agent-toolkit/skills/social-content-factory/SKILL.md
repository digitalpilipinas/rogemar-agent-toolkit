# Social Content Factory

## Workflow

1. Identify the source, audience, channel mix, tone, and call to action.
2. Extract the strongest claims, story beats, proof points, and user benefits.
3. Create channel-native outputs instead of resizing the same paragraph everywhere.
4. Include hooks, captions, alt-text ideas, hashtags only when useful, and visual prompts for carousel or image posts.
5. Preserve factual accuracy and cite or link back to the source when needed.

## Channel Defaults

- LinkedIn: practical insight, founder/product angle, clear takeaway.
- X/Twitter: crisp thread or standalone posts with one idea per post.
- Instagram: concise caption, visual-first framing, carousel slide script if requested.
- EVERSO: premium, ocean-aware, community-forward, never fake social proof.

## Guardrails

- Do not invent metrics, endorsements, testimonials, or user counts.
- Keep claims consistent with the source article or verified research.
