# Visual craft within the existing system

Apply these observations only to the affected components, using approved tokens
and platform conventions. They do not authorize a new theme or full redesign.

- Inspect nested rounded surfaces together. For equally inset curves, an outer
  radius related to the inner radius plus inset can be a useful starting point;
  clipping, pills and unequal padding need visual judgment. Preserve token usage
  rather than imposing a formula everywhere.
- Compare geometric and optical alignment for asymmetric icons and mixed text.
  Prefer correcting the shared asset or component alignment over scattered offsets.
  Verify at rendered sizes, text scaling and relevant writing directions.
- Distinguish elevation from structure: an existing shadow token can convey depth,
  while borders may communicate separation, selection or focus. Do not remove
  meaningful boundaries or reduce contrast to satisfy a stylistic preference.
- Keep icon family, apparent weight and sizing coherent with adjacent typography.
  Reuse supported variants and state colors; do not impose a universal stroke
  width or outline/fill rule. Preserve accessible naming and non-color state cues.

Inspect affected themes, narrow layouts and focus states. Record unavailable
rendered evidence honestly. Use the existing finding record and scope boundary.
