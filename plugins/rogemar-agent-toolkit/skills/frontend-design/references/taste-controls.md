# Contextual Taste controls

Adapted 2026-09-07 from Leonxlnx's MIT-licensed Taste material distributed by
OpenDesign; see [provenance.md](provenance.md) and
[LICENSE.taste.txt](../LICENSE.taste.txt). These are reusable methods, not a
claim to reproduce the author's whole design philosophy or a private profile.

Use this lens for marketing pages, portfolios, editorial experiences and
redesigns where visual direction is part of the request. Establish page kind,
audience, reference signals, supplied brand assets and constraints first.
Choose values from the current brief; there is no global `8 / 6 / 4` default.

| Control | Question it resolves | Useful range |
|---|---|---|
| Composition variance | How much surprise helps this audience? | Predictable alignment through selective asymmetry to expressive composition |
| Motion intensity | What movement supports explanation or feedback? | Static/instant through restrained transitions to explicit creative choreography |
| Visual density | How much information needs to be compared at once? | Spacious storytelling through everyday interfaces to compact operational views |

Numeric dials are optional shorthand, not quality scores. A public service
flow, repeated dashboard action or accessibility need can call for restraint.
An expressive direction still needs readable content, narrow-screen behavior,
input alternatives and a useful reduced-motion state.

For redesigns, record keep/change boundaries and first inspect typography,
alignment, hierarchy, content and actual interaction states. Fix the highest
impact mismatch before adding visual effects. A meaningful design system can
be more appropriate than a bespoke visual style.

Avoid accidental defaults: repeated interchangeable feature cards, gratuitous
glow, decorative motion, missing states, vague copy or arbitrary layout variety.
Treat these as questions about the artifact's purpose, not universal bans on
particular colors, fonts, layouts or emoji. Preserve the user's chosen brand.

Do not import mandatory React/Next/Tailwind/GSAP choices, forced infinite
animations, simulated randomization, compulsory AIDA structure or fabricated
tool execution from upstream variants. Choose the composition deliberately;
use an actual experiment only when it resolves uncertainty. Continuous motion
must be justified, isolated from unrelated updates, interruptible where needed
and checked for performance and accessibility on the target surface.
