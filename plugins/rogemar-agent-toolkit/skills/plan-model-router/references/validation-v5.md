## Controlled fresh work

Sixteen workers: four routine candidates, two ordinary Scout receipts, four UI
candidates and six matching parent-profile UI baselines. Each selected profile/case
has exactly two fresh repetitions. Existing v4 routine baselines reuse the identical
packet and the same 19-check SQLite harness. No entire historical benchmark reran.
The UI exercise qualifies three adjacent functions from one artifact; it is not
three independent trials. Graders saw anonymous outputs and screenshots without
candidate identities or usage. The main agent reconciled concrete defects against
source and checks. Candidate code was never repaired for promotion.

The locked packets, source, answers, criteria, native-profile evidence, checks and
usage are preserved in [validation-v5.json](validation-v5.json). Worker models and
efforts were verified from native runtime records. This does not test parent
coordination or switch the running parent. Scout has no matching higher-parent
comparison on the new packet; its bounded qualification is not a causal cost claim.

Routine usage is for the entire 31-focus packet plus SQLite artifact, never a

Main-agent coordination, subsequent policy review and dispatch verification are outside those totals; they are not complete implementation costs.

## Failures and retained limits

- Terra/high UI repetition 2 clears Saving/Saved through its own error helper;
  three required browser checks fail. No repeated trial was used to erase it.
- Terra/xhigh UI repetition 2 marks valid input invalid on a network failure.
  The blind source review catches this despite passing automated browser checks.
- Every fresh routine candidate still omits part of bug triage. Several snippets
  contain literal backslash-newlines; three refactors change missing-ID behavior.
  These candidates were not promoted for feature, refactoring or triage.
- One Terra/high SQLite artifact is malformed as supplied; both Terra/medium
  SQLite artifacts pass. This does not prove a performance improvement, a UI
  implementation or general full-feature competence.
- New normal UI assignments in Lean/Economy remain provisional. A concrete need
  can request the exact scoped Sol/high hard-task UI consultant; explicit hard
  limits still win. A consultation does not satisfy an independent native gate.
- Design-system audits, analytical synthesis, actual browser/device operation,
  larger review waves and complete parent coordination lack representative paired
  coverage. Their narrow readiness/source records must not be presented as broad
  proof. Required target-specific checks remain in the task.
- Max/Ultra were not rejected as slow, costly or low quality. Historical single
  observations were considered but provide no matching paired promotion proof.
  They exceed the normal effort ceilings and remain available in exact Default
  or separately qualified, practically needed exceptions.

One Astra/xhigh UI repetition additionally distinguished edits made during an
in-flight save from the saved text. That is a useful observed safeguard, not a
required criterion in this locked packet or proof of universal superiority.

## Routing and receipt review

Independent policy review reproduced all 225 decisions and found two defects:
SQLite exceptions could bypass the UI-specific failure through a generic hard-role
label, and Scout ledger text still described the old missing ordinary pair. Both
were corrected. Alternate implementation and all exceptions now require a matching
`evidence_contract`; the dispatcher must relate it to the actual task, not copy a
convenient ID. UI parent fallbacks also disclose the recorded UI failure.

Two separate post-update Scout probes verified Luna/medium native profiles. The
first explorer preset added unsolicited fix advice; the corrected unpinned default
assignment returned only source evidence, matching the type used in the successful
paired trials. Read-only scope is instructional, not a claim of tool sandboxing.
The native GoalBuddy Scout/Low and Judge/High bindings remain unchanged. These
probes are routing/handoff evidence, not extra qualification repetitions.
