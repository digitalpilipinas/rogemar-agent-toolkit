## Hero generation prompt

Use case: stylized-concept. Asset: a wide 3:1 hero illustration for the Rogemar Agent Toolkit GitHub README, no words. Original premium editorial 3D visual: a coordinated toolkit made of six precision-machined modular blocks on a deep midnight navy surface. An open central hexagonal hub with a glowing cyan core joins smaller cyan glass and warm coral enamel modules using orderly luminous paths. Each module suggests a simple function through geometry: blueprint grid, code brackets, a magnifying lens, a checkmark tile, a stacked package, a branching node. Strong visual hierarchy, sculptural soft bevels, subtle material grain, clean cinematic studio lighting, restrained bloom, refined shadows. Composition fills the wide frame with a flowing left-to-right sequence, generous breathing room around objects, no dense microdetail, legible as a small banner. Colors: midnight navy #081525, cyan #48D7E8, coral #FF826C, warm off-white accents. Bold, sophisticated, cohesive, purposeful, not a generic futuristic circuit board. No humanoids, no robots, no mascots, no screens or fake UI, no letters, no numbers, no third-party logos, no watermark.

## Interactive showcase assets

- `ownership-{light,dark}.png`, `task-loop-{light,dark}.png`, and
  `installation-{light,dark}.png`: original toolkit diagrams rendered from the
  SVG/HTML in `docs/showcase/diagrams/`. No remote assets or fonts.
- `workflow-demo.gif`: seven browser-rendered frames, 4.3 seconds total, with no
  looping extension. It illustrates the task method; it is not an agent recording.
  A complete static frame and controllable gallery provide alternatives.
- Layout methods are adapted from Cathryn Lavery's MIT Diagram Design at
  `7a2e22170ee838e859d8142ba825d83f8b6375e6`; illustration content and branding
  were authored for this toolkit. The upstream license remains with the skill.

Reproduction: rebuild SVG/HTML with `python3 scripts/build_showcase.py`; use
`scripts/check_showcase.cjs` with an already installed Playwright/browser to
capture the six PNGs and seven frames. Copy PNGs into this folder and run
`python3 scripts/build_showcase_demo.py <captures> docs/assets/readme/workflow-demo.gif`
with an existing Pillow installation. Rendering tools are authoring prerequisites,
not dependencies for viewing the README/gallery. No upstream branding is copied.
